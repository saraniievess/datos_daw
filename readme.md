# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Netflix
- Contexto: plataforma de streaming que usa grandes volúmenes de datos para recomendar contenido personalizado a cada usuario.

## 2) Conceptos
- Big Data: conjunto de datos masivos, complejos y variados que no pueden ser gestionados con herramientas tradicionales.
- Análisis de datos: proceso de examinar, limpiar y transformar datos para extraer información útil.
- Machine Learning: técnica que permite a los sistemas aprender patrones a partir de datos y hacer predicciones sin programación explícita.
- Deep Learning: subcampo del Machine Learning basado en redes neuronales profundas que analizan datos complejos.
- IA: conjunto de tecnologías que permiten a las máquinas tomar decisiones o simular inteligencia humana.

## 3) Relación
- Los datos generados por los usuarios (Big Data) se procesan y analizan (análisis de datos). Luego, se entrenan modelos de Machine Learning y Deep Learning que detectan patrones. Estos modelos forman parte de un sistema de IA que toma decisiones automatizadas (por ejemplo, recomendar una serie).
